# B10 — Physical Phase Mutation Laboratory

## Philosophy: math changes time, not animation speed

B10 takes the actual **two-stage Wireworld NAND→synchronized NOT→AND specimen** from B9 and alters its **discrete spatial wire lengths**. Each extra conductor cell is an extra real state transition for a traveling electron wave. No Boolean shortcuts, separate animation clocks, fake output injection, or renderer tricks.

Users have **two independent controls** from **−3 to +3 cells**: the northwest and northeast bias arm length. If the original B9 bias source is r+1 conducting steps upstream of the second junction, B10 starts that source r+1+shift steps upstream. **0/0 recovers B9 exactly.** Both controls manipulate the original canonical four-state Wireworld lattice (0 EMPTY, 1 CONDUCTOR, 2 ELECTRON HEAD, 3 TAIL), whose conductor excitation remains 1–2 Moore-neighbor HEADS.

This is a *phase change generated by actual spatial geometry*: a late NW signal means adding cells to that rail, not withholding a head for a number of JavaScript milliseconds. Negative phase shortens the rail.

## User-facing B10 instrument

The dedicated **PHASE MUTATION LAB** sits alongside B3–B9 Wireworld instruments, without obscuring the live artboard. It offers:
- two sliders altering NW and NE independently, radius and output path length, all four cardinal rotations;
- a four-input truth table with **measured** NAD/NAND source-port heads, NW/NE bias arrivals, second junction HEADs, and remote-port HEAD times across each full run, including reflections and late spurious output pulses;
- a measured **four-bit fingerprint** in 00,01,10,11 order for the current physical geometry; **0001** is the baseline B9 AND fingerprint, but other geometries are never falsely labeled certified reusable AND;
- **Restore perfect synchronization**, explicitly resetting both physical wire-length adjustments to zero;
- **Scan five physical NW phases**, a user-triggered spectrum with NE held constant, observing the actual complete output waveforms for input combinations. This is **not continuously recomputed** every time the artboard redraws, preventing gratuitous work on an iPhone;
- an **Install phase-mutated specimen** button, which writes genuine 0/1/2/3 states into an isolated bounded region of the existing live world. The operation preserves generation and artwork outside the local clearing moat and rejects clipped circuits atomically. It never silently changes a user's physics settings;
- a 64-generation copy-based **real four-point oscilloscope** reading both bias contacts, the detector, and final output directly from the CURRENT stage, independently of the canonical isolated bench. Measured results warn if a different circuit or generation has since been selected. This is read-only, not a speculative renderer.

All circuit states persist through the existing exact saved-world recipe and output in the original GIF/video export pipeline. Probe attachments are ephemeral diagnostic UI rather than fabricated stored metadata.

## Scientific honesty

A full four-state circuit can become silent or produce additional pulses when contact signals desynchronize. An output bit in the fingerprint means **at least one real HEAD reached the remote port within the measured horizon**, not that a single clean clocked bit emerged. For that reason the table also displays **every observed head arrival tick**, and strict AND certification is reserved for B9's original perfectly synchronized physical geometry.

The NAND port can exhibit a returning HEAD (reverse propagation) after stage two fires, as discovered during B9. B10's measurements include that genuine feedback rather than concealing it.

The change in geometry can alter or destroy AND behavior even though every site still follows exactly the same original Wireworld law. No arbitrary asynchronous input gates, self-resetting latches, periodic clocks or isolated two-wire crossover are claimed.

## Acceptance gates

- Prove the zero/zero geometry remains **identical to B9** for 6 input-stage radii × 3 output lengths × 4 truth rows, with exact NAND, both bias, second junction and remote output arrival lists.
- Independently run the real Wireworld stepper on a full isolated lattice with every configuration of two bias offsets from −3..3 and validate physically measured pulse times, including positive delayed paths and negative shortened paths. Truth fingerprints must not be generated by a Boolean lookup.
- Compare **144 integrated rotated true-world circuits** under selected radii, orientations, offsets and input bits against the independent phase bench (all five port traces), exact JSON recipe replay and no external injected heads. Reject invalid/noninteger offsets and clipped physical geometry before mutation.
- Verify the on-demand 5-row phase spectrum and immutability of a 64-tick four-point real-artboard probe. The live artwork and generation must not change during measurement or scanning.
- TypeScript production build, B1–B9 numerical tests, browser controls in phone-width Chromium, GIF worker and video capture, Netlify preview. Test on real iPhone Safari after merge.
