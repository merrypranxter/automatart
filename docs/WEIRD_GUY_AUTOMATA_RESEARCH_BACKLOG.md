This is an appended research backlog, not a change to the approved D1B → D1C → D2–D4 → F6 implementation order. No item below is claimed to be implemented.

## Research engines and interventions (after the existing queue)

1. **Temporal Anarchy / Paint With Time** — seeded asynchronous cell schedules, editable per-site update probabilities and actual spatial time-rate brushes. State transition must change, not only preview or playback speed; exact deterministic recipe/capture replay. Initially target compatible local cell rules; reversible and agent engines require separate semantics.
2. **Lenia / Flow Lenia** — continuous field states, growth kernels, smooth organic morphogenesis and interactive parameter steering. Genuine continuous solver; desktop/GPU/mobile computational budgets and numerical stability tests.
3. **Hyperbolic automata** — true Poincaré-disc tessellation graph and locally propagating rules. Boundary is a visualization of geometric infinity, not a finite square fisheye skin.
4. **Physarum hybrid ecosystems** — chemotactic swarms that deposit/respond to real diffusing fields and optionally interact bidirectionally with reaction-diffusion/ant ecologies. Label agent/field hybrids honestly.
5. **Particle Lenia** — grid-free attraction/repulsion energy-gradient particle evolution and compatible multi-species interactions; independent from cell-indexed life.
6. **Neural cellular automata / regeneration** — pretrained or locally trained differentiable update rules, hidden-state signaling, deliberate wounds, scarred or partially failed regrowth; do not claim this for untrained standard CA.
7. **Audio ↔ automata law coupling** — audio bands alter real kernels, update thresholds and boundary conditions; optional measured CA features sonify sound. Preserve offline deterministic recording using saved driving signals.
8. **Living 3D mathematical sculptures** — surface graph automata and volume rules with 3D rendering, raymarching/SDF presentation and optional printable geometry; distinguish real volumetric simulation from 2D aesthetic extrusion.
