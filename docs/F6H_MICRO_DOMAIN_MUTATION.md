# F6H — Micro Domain Mutation

The nine true microscopic mathematical skins have living color, time, and angle from F6G. F6H adds selectable **nonlinear coordinate-domain equations** evaluated **inside** each physical cell; it does not fake new cellular lattices by reshaping the rendered image or move actual polygons.

## Three morphisms

- **Complex Power:** normalized complex polynomial z → z^n, with 2–8 integer power. Produces actual nonlinear angular multiplication, high-order lobes, and radial compression toward the center.
- **Kaleidoscopic Folding:** the analytic fundamental angular wedge theta → acos(cos(n·theta))/n. This reflects/mirrors local mathematical domains into N-fold repeating sectors, not CSS kaleidoscope overlays.
- **Vortex Twist:** radial angular shear theta → theta + 0.55·n·max(0,1−sqrt(2)·r)^2. This smoothly twists sample coordinates with a stronger turn near the center.

**Order 2–8** determines branch/fold count or vortex winding. **Living field coupling 0–2** advects the transformed sampling domain using previously computed real physical neighborhood gradients and occupancy/Laplacian; it does not participate in automaton transitions. Both are live Skin Laboratory controls for all nine math skins when subcell detail is enabled.

All transforms occur after F6G local rotation and before the original gyroid, inversion, cusp, spinodal, interference, etc. formulas are evaluated. Exact original polygons still clip the actual samples on all eight lattices. Strict original preview/export evaluation budgets and no full-frame shader buffers.

## Preservation

Default mode is **OFF (none)** and gives exact old F6G image even with nondefault order/coupling. Quality 0 or intensity 0 ignores all domain controls. Older recipes with no F6H fields load identically; malformed imports validate safely. Reset Skin Laboratory disables the transformation. All changes depend on fixed recipe and generation (no separate running clock), so snapshot replay and PNG/GIF/video remain deterministic.
